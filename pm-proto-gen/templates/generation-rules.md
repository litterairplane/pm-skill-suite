# 原型生成方式与组件解析规则

本文件从 SKILL.md Phase 1 Step 3 提取，供生成原型时按需读取。

## 生成方式判断

| 优先级 | 场景 | 判断条件 | 生成方式 |
|--------|------|---------|---------|
| 0 | 基底快照优先 | 原型基底库 index.md 中该页面有快照 | 直接读快照作为基底,叠加新功能 |
| 1 | 原型迭代 | `原型/` 下已有对应 HTML | 在已有页面基础上修改 |
| 2 | 存量页面改造 | PRD 功能在已有页面上增改，原型目录无对应 HTML | 从 Vue 源码还原后叠加新功能 |
| 3 | 全新功能 | 现有系统中不存在该页面 | 从零生成 |

**互斥规则**：优先级 0 命中时优先于 1/2/3。优先级 1 命中时优先于 2/3。仅当 `原型/` 下无对应 HTML 且 PRD 功能涉及已有页面增改时，才走"存量页面改造"。

---

## 基底定位步骤（Phase 1 Step 1 前置）

> 优先级 0 的判断与基底加载逻辑。在"分析输入文档 + 前端代码"之前执行。

1. **判断需求所属系统**：xkf / qc / knowledge（根据需求涉及的业务模块或用户指定）
2. **读取基底索引**：`~/Developer/my-project/原型基底/{系统}/index.md`
3. **按需求功能清单匹配 index.md 中的页面**（按路由路径或功能名匹配）
4. **对每个匹配页面**：
   - 快照列非空（指向 `snapshots/{页面}.html`）→ 读该快照作为基底，走"原型迭代"路径（优先级 0）
   - 快照列为"待生成" → 按 Vue 路径读 Vue 文件，走"存量页面改造"路径（优先级 2）
5. **索引未覆盖的新页面** → 走"全新功能"路径（优先级 3）
6. **多系统跨页**：分别按各系统 index.md 定位，混合使用上述路径

> 基底索引由 `pm-knowledge update` 定期校验漂移。若 index.md 头部"校验状态"为 ⚠️N条漂移，对应页面快照可能过期，应在 proto-banner 中标注"基底快照可能漂移"。

## 原型迭代步骤
<!-- anchor: proto-iteration-steps -->

1. 加载已有原型全部文件（HTML/CSS/JS）
2. 定位修改范围并**搜索全部出现位置**（不同 Tab、不同页面中的相同字段）
3. 按变更清单逐处编辑，未涉及改动区域保持不变
4. 标记变更点（按页面类型模板 §变更标记规范）
5. 更新 proto-banner 改动摘要
6. 交互状态检查（按页面类型模板 §交互组件状态展示规范）
7. **回归检查**：验证未涉及修改区域的弹窗开关、Tab 切换、导航链接是否正常

---

## 存量页面改造步骤

1. 识别目标 Vue 文件，读取并提取 DOM 结构
2. 原样还原为 HTML（保持字段顺序、列顺序、按钮位置不变）
3. 叠加新功能并标记变更（NEW/UPDATED/删除线）
4. 在 proto-banner 中列出改动点摘要

---

## Vue 组件解析规则（存量改造专用）

| 场景 | 处理方式 |
|------|---------|
| 自定义组件 | 递归读取子组件定义，提取 DOM 结构后还原 |
| Element UI 组件 | 转为原生 HTML 对应结构 |
| 动态数据（`v-for`） | 转为 5-8 行静态示例数据 |
| 条件渲染（`v-if`/`v-show`） | 展示最常见/默认状态；权限差异展示管理员（权限最全）视角，不同角色差异在 proto-banner 中注明 |
| 插槽 | 将父组件插槽内容内联 |
| 找不到子组件定义 | 先向用户确认是否路径有误并提供候选建议（基于文件名模糊搜索），确认无法定位后推断结构，用 `<!-- ⚠️ INFERRED -->` 标记 |

**降级策略**：若确认无法定位 Vue 文件，退化为全新功能模式，在 proto-banner 中注明。

## 前端样式参考源

| 优先级 | 参考源 | 说明 |
|--------|--------|------|
| 0 | 基底快照样式 | `~/Developer/my-project/原型基底/{系统}/snapshots/{页面}.html` | 优先复用 |
| 1 | 已有原型样式 | 从当前需求 `原型/` 目录下已有原型 HTML `<style>` 或 `styles.css` 提取，优先复用 |
| 2 | 项目全局样式 | `~/Developer/Projects/xkf/xkf.win.oa.com/src/styles/global.scss` |
| 3 | 项目自定义样式 | `~/Developer/Projects/xkf/xkf.win.oa.com/src/styles/custom/index.scss` |
| 4 | 公共组件模板 | `~/Developer/Projects/xkf/xkf.win.oa.com/src/components/page/` |
| 5 | 典型页面参考 | `~/Developer/Projects/xkf/xkf.win.oa.com/src/views/role/index.vue` |

- **优先级 0 存在时**：直接复用基底快照样式，仅追加新组件样式时参考优先级 4
- **优先级 0 不存在、优先级 1 存在时**：直接复用，仅追加新组件样式时参考优先级 4
- **优先级 0/1 都不存在时**：读取样式模板，参考优先级 2-5 校验参数，有差异以项目实际值为准
