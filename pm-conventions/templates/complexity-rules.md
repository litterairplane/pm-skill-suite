# 复杂度判断与自适应规则

> [适用范围] 本文件适用于 pm-req-analysis（Phase 1.5）、pm-baseline-gen（Phase 2）。

## pm-baseline 复杂度判断

| 维度 | 简单需求 | 复杂需求 |
|------|---------|---------|
| 涉及系统数 | 1 个 | 2+ 个 |
| 涉及功能点数 | 1-3 个 | 4+ 个 |
| 是否有新数据模型 | 否 | 是 |
| 是否需要新角色/权限 | 否 | 是 |

| 环节 | 简单需求 | 复杂需求 |
|------|---------|---------|
| 澄清轮次 | 2-4 轮 | 最少 5 轮，不设上限 |
| Baseline | 精简（5-15 条规则） | 完整（15+ 条规则） |
